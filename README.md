# 💅 Estética Mariana - Landing Page

Una landing page moderna, elegante y totalmente adaptable a dispositivos móviles, diseñada para un centro de estética y spa.

🌐 **Demo en vivo:** [estetica-mariana.netlify.app](https://estetica-mariana.netlify.app)

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica.
* **CSS3:** Estilos personalizados y diseño visual.
* **Bootstrap 5:** Sistema de rejilla responsive y componentes interactivos.
* **Netlify:** Hosteo y despliegue continuo (CI/CD).

---

## ✨ Características Principales

* 📱 **Diseño 100% Responsive:** Adaptado perfectamente a móviles, tablets y escritorio.
* ⚡ **Carga Ultra Rápida:** Optimización de recursos e imágenes.
* 💄 **Secciones Incluidas:** Presentación de servicios, agenda de citas y contacto.
